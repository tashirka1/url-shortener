## Почему

URL-шортениры в первую очередь используются программно — CI/CD пайплайны, CMS-плагины, планировщики соцсетей и кастомные скрипты создают короткие ссылки без браузера. Сейчас единственный способ создавать/управлять ссылками — веб-интерфейс с cookie-сессией, что полностью исключает автоматизацию.

## Что меняется

- Новая таблица `api_token` и модуль `internal/apitoken/` (model, storage, service, handler, views) для управления токенами
- Прослойка API-авторизации, проверяющая заголовок `Authorization: Bearer <token>`
- REST-эндпоинты `/api/v1/` для создания, получения списка и удаления ссылок (привязка к владельцу токена)
- Интерфейс в дашборде для генерации, копирования и отзыва токенов
- Goose-миграция для новой таблицы и индексов

## Возможности

### Новые возможности

- `api-token-management`: Генерация, просмотр и отзыв API-токенов через веб-интерфейс. Каждый токен — криптостойкая случайная строка, привязанная к пользователю, с человекочитаемым именем и опциональной отметкой последнего использования.
- `rest-api`: REST API на `/api/v1/` с авторизацией через Bearer-токен. Эндпоинты: `POST /api/v1/link` (создать), `GET /api/v1/link` (список), `DELETE /api/v1/link/:code` (удалить), `GET /api/v1/link/:code/stats` (статистика кликов).
