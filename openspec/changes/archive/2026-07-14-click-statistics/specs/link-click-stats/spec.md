## ADDED Requirements

### Requirement: Record click on redirect

Система SHALL записывать каждый переход по короткой ссылке в таблицу `link_click` с информацией об источнике перехода.

#### Scenario: Successful click recording
- **WHEN** пользователь переходит по короткой ссылке `/CODE`
- **THEN** система записывает в `link_click` id ссылки, referrer (из HTTP-заголовка), время перехода
- **AND** `link_link.clicks` инкрементируется
- **AND** пользователь получает HTTP 302 редирект на исходный URL

#### Scenario: Click without referrer (direct visit)
- **WHEN** пользователь переходит по короткой ссылке напрямую (без HTTP Referer)
- **THEN** `referrer` сохраняется как пустая строка
- **AND** редирект выполняется нормально

#### Scenario: Click on deleted link
- **WHEN** пользователь переходит по коду несуществующей ссылки
- **THEN** клик НЕ записывается
- **AND** пользователь получает 404

### Requirement: View click statistics

Система SHALL отображать страницу статистики для каждой ссылки с графиком кликов по дням и списком реферреров.

#### Scenario: Daily click chart
- **WHEN** владелец ссылки открывает страницу статистики `/link/:code/stats`
- **THEN** система отображает bar chart (inline SVG) кликов за последние 30 дней
- **AND** каждая колонка соответствует одному дню
- **AND** высота колонки пропорциональна числу кликов в этот день

#### Scenario: Top referrers list
- **WHEN** владелец ссылки открывает страницу статистики
- **THEN** система отображает таблицу топ-10 реферреров
- **AND** таблица содержит колонки: источник, количество переходов
- **AND** реферреры отсортированы по убыванию числа переходов

#### Scenario: Access denied for non-owner
- **WHEN** пользователь, не являющийся владельцем ссылки, открывает `/link/:code/stats`
- **THEN** система возвращает 403

#### Scenario: Stats for non-existent link
- **WHEN** пользователь открывает статистику по несуществующему коду
- **THEN** система возвращает 404

### Requirement: Navigate to statistics

Система SHALL предоставлять ссылку на страницу статистики из списка ссылок пользователя.

#### Scenario: Stats link in link table
- **WHEN** пользователь просматривает список своих ссылок
- **THEN** каждая строка таблицы содержит кнопку/ссылку «Статистика»
- **AND** нажатие ведёт на `/link/:code/stats`
