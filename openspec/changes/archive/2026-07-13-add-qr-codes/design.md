## Context

Пользователи создают короткие ссылки для печатных материалов, визиток и рекламы. Сейчас QR-код можно получить только через сторонний сервис. Добавляем встроенную генерацию через `skip2/go-qrcode` — библиотека встраивается в бинарник, никаких внешних зависимостей.

## Goals / Non-Goals

**Goals:**
- Генерация QR-кода PNG для любой ссылки пользователя
- Кнопка "QR" в каждой строке списка ссылок
- Модальное окно с QR-кодом и ссылкой
- Минимальное изменение существующей архитектуры

**Non-Goals:**
- Статистика кликов (отдельная задача)
- Кастомизация QR (цвета, логотип, размер) — Medium, 256px
- Bulk-генерация QR
- Скачивание/печать QR

## Decisions

### 1. Библиотека: `skip2/go-qrcode`
- Самая популярная Go QR-библиотека. Генерирует PNG из строки одной функцией.
- Не требует external бинарников или API.
- `qrcode.Encode(url, qrcode.Medium, 256)` → `[]byte` → отдаём как `image/png`.

### 2. Куда: новый хендлер в `link/handler/`
- QR — это ещё один способ получить ссылку. Логика тривиальна: взял URL → сгенерировал PNG.
- Выделять отдельный модуль `qr/` — overengineering. YAGNI.

### 3. Эндпоинт: `GET /link/:code/qr`
- Авторизованный (в группе `/link` с `AuthMiddleware`).
- Возвращает `Content-Type: image/png`.
- Валидация: проверяем, что ссылка существует и принадлежит пользователю.

### 4. UI: htmx + модальное окно
- `<button hx-get="/link/:code/qr" hx-target="#qr-modal" hx-swap="innerHTML">` — запрос возвращает HTML с `<img>` и кнопкой закрытия.
- Модалка: `<dialog>` от PicoCSS (нативный `<dialog>`).
- После закрытия очищаем содержимое модалки через `hx-on:click`.

```
Поток:
┌──────────┐   hx-get="/link/abc123/qr"   ┌─────────────┐
│  Кнопка  │─────────────────────────────▶│  handler.go  │
│  "QR"    │                              │  GetQRCode   │
└──────────┘                              └──────┬──────┘
       ▲                                         │
       │           HTML с <img> src=data:base64  │
       │  ◄──────────────────────────────────────┘
       │
  ┌────┴────┐
  │ <dialog>│  QR modal
  │  modal  │
  └─────────┘
```

### 5. Формат: data URI (base64) вместо отдельного запроса
- Альтернатива: отдавать `/link/:code/qr.png` как image/png и делать `<img src="/link/abc123/qr.png">`.
- Но это значит два запроса на каждое открытие модалки. Base64 data URI — один запрос, <1KB overhead для PNG ~800 байт. OK для такого размера.

## Risks / Trade-offs

- **Размер data URI**: QR 256px Medium ~700-900 байт PNG → ~1.2KB base64. Незначительно.
- **Кеширование**: data URI не кешируется браузером. При каждом открытии модалки — новый запрос. Если станет проблемой — перейти на отдельный image endpoint. Пока не проблема.
- **skip2/go-qrcode 3.2k stars**: проект стабильный, но обновления редкие. Альтернатива — `boombuler/barcode`, но сложнее API.
